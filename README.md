# ご機嫌に暮らす、人生の後半戦。

あらい りょうた（RYOTA ARAI）の個人ブログ。

## しくみ
- Jekyll（GitHub Pages標準）による静的サイト。`main` にpushすると自動でビルド・公開されます。
- 記事は `_posts/` のMarkdownファイル。
- 記事の投稿・編集は `https://pinappe0305.github.io/admin/`（Sveltia CMS）から。
- 記事は「公開する」をオンにしない限りサイトに表示されません（誤公開防止）。

## よく触るファイル
- `_config.yml` … サイト名・SNSリンクなど基本設定
- `assets/css/style.css` … デザイン
- `admin/config.yml` … CMSの入力項目
